## 📌 About

A modern Password Manager built using **HTML, CSS and JavaScript**.

This application allows users to securely save website credentials inside the browser using **Local Storage**.

The project focuses on CRUD operations, DOM Manipulation, Local Storage and modern JavaScript concepts.

---

# ✨ Features

✅ Save Website Credentials

✅ Store Data in Local Storage

✅ View Saved Passwords

✅ Hide Passwords

✅ Copy Username

✅ Copy Password

✅ Delete Password

✅ Edit Password

✅ Update Password

✅ Responsive Layout
